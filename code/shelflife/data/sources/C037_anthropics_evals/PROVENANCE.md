`persona/psychopathy.jsonl` contains 1,000 released statements/questions with matching and
nonmatching behavior answers. Appendix B.2 of Many-shot Jailbreaking explicitly identifies this repository.
`paper-local.txt` is a copy of the earlier text extraction of the April 2 2024
Anthropic paper PDF (the claim record's URL). No original experiment code or model outputs
were found in this data repository. Wrapper, whitespace, decoder settings and evaluation split are
unavailable; executable reconstructed variants label each choice as a deviation.
