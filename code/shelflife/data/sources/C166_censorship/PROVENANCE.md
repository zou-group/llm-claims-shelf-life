# C166 source provenance — retrieved2026-10-15

Primary: Noels et al., *What Large Language Models Do Not Talk About*, arXiv2504.03803v1 (2025-04-04), https://arxiv.org/abs/2504.03803v1 . `paper.html`, `paper.pdf` are original snapshots. Fig3a values read independently from the PDF by source auditor, not inferred from the archive.

Original LIA code: https://github.com/aida-ugent/llm-ideology-analysis commit `de901f284f8d9fd288779745c9f3b42e1cec6536`. `github_tree.json` is the pinned tree; `repo/` contains original .py/.md/.toml sources downloaded via commit-specific raw URLs (not a git clone). `src/stage_1_cross_check.py` supplies generate_message and original label cleaning. `src/utils/chat.py` gives judge params temperature0/max_tokens2048. Source classifier protocol differs from paper diagram: REFERENCE beforeTEST and duplicated system text in user message. Original LIA subject stage_1 is a plain user request with no system message or decoding params in Together path. Sources are unmodified.

Original LIA dataset: https://huggingface.co/datasets/aida-ugent/llm-ideology-analysis revision `e9e8843b84031b4ce58a8a59eba9d9103b7261cf`. Original `responses/invalid.csv`, `people_tagged/summaries.csv`, `people_tagged/tags.csv` preserved as `invalid.csv`, `summaries.csv`, `tags.csv`. `valid_columns_*.parquet` retain exact eight original columns from the three public Parquet-converted valid partitions. `parquet_inventory.json` and `column_acquisition.json` record URLs, row counts, selected columns, downloaded table hashes; `prepared_manifest.json` additionally hashes all raw input files used. Original raw judge prose is unavailable; `stage_1_response_valid` contains cleaned author labels. The valid/invalid files refer also to second-stage ideological-rating validity; a first-stage yes label can therefore occur in invalid.csv. Both partitions are required and unioned without treating filename as a first-stage label.

Official Pantheon2020: https://storage.googleapis.com/pantheon-public-data/person_2020_update.csv.bz2 . Independently downloaded. Cohort `political_cohort.csv`: join3,991LIA IDs to Pantheon wd_id, restrict occupations POLITICIAN, MILITARY PERSONNEL, SOCIAL ACTIVIST, DIPLOMAT, POLITICAL SCIENTIST. Exactly2,371people, matching paper. This avoids deriving the population from non-refused soft-censorship records.

Censorship supplementary data: https://huggingface.co/datasets/aida-ugent/llm-censorship revision `7ed9ed80dde0f3e22bb579af14ce087a9c5c2092`. `responses.csv` there is 1,380 soft-framework classification rows, NOT the original model-generation dataset; not used for C166. Public dataset is CC-BY4.0. No third-party licenses changed. `soft_ids_*.parquet` from a discontinued population-identification attempt are unused.

Derived `items.jsonl`: exact all-six-language Qwen prompts and first1000character reference Wikipedia excerpts for each cohort person. `qwen_archived.jsonl`: all14,226 raw biography responses and author cleaned labels. `subject_templates.json`: six source prompt patterns, validated byte-for-byte against every Qwen record. Two original empty-name prompts for Q57641 in French/Spanish are intentionally preserved rather than repairing the source. `all_model_labels.jsonl`: cohort labels across original LIA models, for secondary calibration only. Exact records are regenerated by `experiments/political-censorship-reproduction/prepare.py` and source assertions.

No new inference during acquisition/preparation. Archived scores cannot prove current API performance or the semantic accuracy of original classifier labels.
